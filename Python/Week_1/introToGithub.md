Questions
1. What is Git, what is Github, and what is the difference between the two?
Git is a version control that tracks changes. GitHub is the website built around it.

2. What is the difference between a local repository and a remote repository?
Local saves to device. (GitHub Desktop)
Remote saves to internet/cloud. GitHub.com

3. What does the push command do in Git?
Push uploads changes from local repo to remote repo.

4. What does the commit command do in Git?
Commit saves from remote repo to local repo.

5. What is Github Desktop, & why are we using it?
GitHub Desktop is a simplified version of Git and GitHub that doesn't require commands.
